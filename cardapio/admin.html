Publicar no site

São duas coisas diferentes. Leia com calma que é rápido.

1. Salvar neste aparelho Vale só no seu celular, serve para você conferir como ficou antes de publicar para todo mundo.
2. Publicar para todos os clientes Aqui você troca o arquivo menu-dados.js no GitHub. A URL do site e o seu QR Code não mudam.

Como colar no GitHub pelo celular

  1. Toque em Copiar o arquivo novo aqui em cima.
  2. Abra o seu repositório no GitHub pelo navegador do celular.
  3. Entre na pasta cardapio e toque no arquivo menu-dados.js.
  4. Toque no lápis ✏️ (Edit). Se não aparecer, toque nos três pontinhos ⋯ e escolha Edit in place.
  5. Apague tudo que está lá dentro (toque e segure → Selecionar tudo → apagar).
  6. Cole o que você copiou.
  7. Desça e toque em Commit changes.
  8. Espere 1 ou 2 minutos e abra o site. O cardápio novo já está no ar, no mesmo link de sempre.
